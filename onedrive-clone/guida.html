Introduzione

Benvenuto in Clone-OneDrive, lo spazio di archiviazione della suite Clone Office. Carica, organizza, scarica e gestisci i tuoi file nel browser, con cartelle, preferiti, ricerca e cestino.

Carica

Trascina o usa "Carica" per aggiungere file.

Organizza

Cartelle, sposta, copia, rinomina, preferiti.

Cestino

Ripristina o svuota gli elementi eliminati.

Caricare file e cartelle

Usa il pulsante Carica nella barra comandi (o trascina i file nell'area). Crea cartelle con Nuovo ▸ Cartella tramite la finestra dedicata.

Gestire i file

Seleziona un file per abilitare le azioni nella barra: Anteprima, Scarica, Rinomina, Elimina, Sposta in, Copia in. Il clic destro apre il menu contestuale completo (anche Aggiungi ai preferiti e Dettagli).

Cartelle e spostamenti

Naviga con il percorso (breadcrumb) in alto. Sposta in e Copia in aprono una finestra elegante per scegliere la cartella di destinazione.

Viste, recenti e preferiti

Cambia tra vista Elenco e Griglia. Nella barra laterale trovi Recenti, Preferiti e le cartelle speciali (Documenti, Foglio, Presentazioni, Blocchi).

Cestino

Gli elementi eliminati finiscono nel Cestino: da lì puoi Ripristinare o Eliminare definitivamente, oppure Svuotare tutto.

Suggerimenti

  • Doppio clic su un file per aprirlo/anteprima.
  • Usa la casella Cerca in alto per filtrare i file.
  • I file dei cloni Office (Word/Excel/PowerPoint) salvati sul server compaiono nelle cartelle dedicate.
