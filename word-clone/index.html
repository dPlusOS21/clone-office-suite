Salva sul Server

Salva il documento corrente sul server. Puoi scegliere il formato e un nuovo nome o sovrascrivere un file esistente.

💾 Salvataggio su Server

Il documento verrà salvato sul server e sarà accessibile da qualsiasi dispositivo.

Suggerimento: usa nomi senza spazi (es: "mia_tesi", "documento_lavoro")
• HTML: Salva solo il contenuto del documento
• JSON: Salva contenuto, orientamento, margini e altre impostazioni
